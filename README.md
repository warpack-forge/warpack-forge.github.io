# Warpack Forge

A searchable reference for the [Warpack](https://store.steampowered.com/search/?term=warpack) demo: every item with its stat lines, backpack combo rules, forge recipes and shop odds by round, plus units, keystones, commanders, skill paths, ascensions and synergies.

Open it here: https://maxq.games/warpack-forge/

Static site, no build step. Data and art reflect the game version shown in the header.
